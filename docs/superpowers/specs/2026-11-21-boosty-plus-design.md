# Boosty Plus — дизайн

Дата: 2026-11-21
Статус: на согласовании

## Зачем

`Boosty_Favorites` умеет только звёздочку. Нужен Boosty Plus: то же избранное плюс раздел «История» — последние 30 постов и видео, которые я открывал, чтобы вернуться к просмотренному без поиска по ленте.

## Цели

- Переименовать скрипт в Boosty Plus: папка, файл, имя, README.
- Раздел «История»: 30 последних открытых постов, свежие сверху.
- Кнопка-часы в шапке слева от звезды открывает историю.
- Избранное продолжает работать, старые данные переносятся.

## Не цели

- Синхронизация между устройствами и сервер.
- Прогресс и продолжение просмотра видео.
- Учёт постов, которые только мелькнули в ленте.
- Поиск по истории: 30 записей быстрее листать.
- Вмешательство в нативную ленту Boosty.

## Анти-цели

- Потерять существующее избранное при обновлении.
- Два скрипта-дубля в Tampermonkey.
- Отправка данных куда-либо.

## Ограничения

- Один userscript-файл, без сборки и зависимостей.
- Boosty — SPA; классы CSS-модулей меняются, поэтому опора на `data-test-id`, `data-post-id`, og-мета и URL.
- Правила репозитория: README в папке, строка в корневом README, повышение `@version`, коммиты на русском.
- `CLAUDE.md` запрещает менять `@name`/`@namespace`, но переименование папки всё равно меняет `@updateURL`. По решению пользователя делаем полный ребрендинг; нужна одна переустановка.

## Подходы

1. **Одна панель, две вкладки — выбрано.** Общий оверлей, список и хранилище; кнопки в шапке открывают нужную вкладку.
2. **Две отдельные панели — отклонено.** Дублирование разметки, стилей и тостов; две панели конкурируют за экран.
3. **История секцией под избранным — отклонено.** История спрятана, списки делят высоту, а на скриншоте у неё отдельная кнопка.

## Решения

- **Триггер.** Открытие страницы поста `/^\/[^/]+\/posts\/[^/]+\/?$/`, включая видео-посты. Запись создаётся сразу, без задержки.
- **Видео.** Если на странице появляется плеер (`video`, iframe ok.ru/video, маркеры Video), запись помечается «видео» и время просмотра обновляется; иначе остаётся постом.
- **Данные записи.** `id`, `url`, `title` (h1 поста, фолбэк — `og:title` без хвоста « - автор»), автор (имя, ссылка, аватар), обложка (`og:image`), дата поста, тип, `viewedAt`.
- **Дедупликация.** По `id`: повторный просмотр поднимает запись наверх. Максимум 30, лишние удаляются.
- **Хранилище.** Новый ключ `tm-boosty-plus` = `{v:1, favorites, history}`. При первом запуске избранное импортируется из `tm-boosty-favorites`; старый ключ не удаляется.
- **Интерфейс.** Одна панель; вкладки «Избранное» и «История» со счётчиками; кнопки в шапке открывают нужную вкладку. Поиск только в избранном.
- **История.** Обложка, заголовок, автор с аватаркой, время («сегодня, 14:32» / «вчера» / дата), бейдж «видео»; у записи кнопка «×»; сверху «Очистить» с отменой через тост.
- **Кнопка.** Плашка 40×40 как у звезды; иконка часов со стрелкой против часовой, обводка 1.8.
- **Версия и имена.** `2.0.0`; `@name` «Boosty Plus», `@namespace` `danil.boosty.plus`, путь `Boosty_Plus/boosty-plus.user.js`; README и корневая таблица обновляются.

## Проверка

- `node --check` синтаксиса.
- Локальный стенд: страница-макет поста; запись, дедупликация, лимит 30, вкладки, перенос избранного.
- Публичный пост Boosty в браузере: запись появляется, повторный заход поднимает её, кнопки и панель не ломают вёрстку.
- После PR: установка из нового URL, проверка обновления версии.

## Что остаётся исполнителю

- Точные селекторы и тайминги ожидания контента.
- Разметка вкладок и стили в духе существующей панели.
- Тексты пустых состояний и тостов.
